出場チームとして、対戦ごとのオーダーを提出する手順をご案内します。

## オーダー提出画面へのアクセス

1. `/auth/login` からチームアカウントでログインする
2. 「**ライブ**」メニューの「オーダー/審判」ページ（`/live/tasks`）を開く
3. 「**オーダー提出**」欄に表示された対戦の「提出」ボタンをタップする

> [!TIP]
> ページは定期的に自動更新されます。提出期限が近い場合はリロードして最新状態をご確認ください。

## オーダーの入力

オーダー提出画面では、5種目のそれぞれに選手を割り当てます。

| 種目          | 略称 | 必要な選手構成     |
| ------------- | ---- | ------------------ |
| 女子ダブルス  | WD   | 女性選手 2名       |
| 混合ダブルス  | XD   | 男性 1名・女性 1名 |
| 男子ダブルス3 | MD3  | 男性選手 2名       |
| 男子ダブルス2 | MD2  | 男性選手 2名       |
| 男子ダブルス1 | MD1  | 男性選手 2名       |

各種目のプルダウンから選手を選択し、すべての種目を埋めると提出できます。

> [!NOTE]
> 性別条件を満たさない選手は選択肢に表示されません。チーム登録時に性別が正しく設定されているかご確認ください。

## 提出後の状態

オーダー提出後は「提出済み」状態になります。提出期限が過ぎると内容を変更できなくなります。

### 相手チームのオーダーの確認

両チームのオーダーが提出され、管理者によって公開されると、相手チームのオーダーを確認できるようになります。

公開後は「**公開済み**」と表示され、5種目すべての選手名が一覧表示されます。

> [!TIP]
> オーダー公開のタイミングは、大会設定により「試合開始時」または「手動公開」のどちらかです。管理者にご確認ください。

## よくあるエラー

| エラー内容                     | 原因と対処                                                                  |
| ------------------------------ | --------------------------------------------------------------------------- |
| 「女性選手が必要です」         | WD / XD に男性選手を割り当てている。選手の性別設定を確認してください        |
| 「同じ選手が複数の種目に出場」 | 1人の選手を複数の種目に登録している。種目ごとに異なる選手を選択してください |
| 「提出期限を過ぎています」     | 期限内に再提出が必要。管理者にお問い合わせください                          |
