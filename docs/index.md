本マニュアルでは **東大リーグ団体戦** の運営支援システムの使い方を、役割ごとにご案内します。

## 対象読者

| 役割       | 該当セクション                                                       |
| ---------- | -------------------------------------------------------------------- |
| 出場チーム | 出場チームマニュアル（オーダー提出・スコア入力・取り消し・棄権処理） |
| 観戦者     | 観戦者向け（ライブスコア・順位表の見方）                             |
| 大会運営者 | 管理者マニュアル（セットアップ・チーム登録・対戦生成・順位管理）     |

## システム概要

本システムは、東大リーグの**団体戦**に特化した運営・スコア管理アプリです。試合の進行状況がリアルタイムでライブページに反映されるため、会場外からでも対戦結果をご確認いただけます。

### 大会の流れ

1. **セットアップ** — 大会名・使用ルールの設定
2. **チーム登録** — 参加チームと選手を A / B の2リーグに振り分け
3. **予選（グループステージ）** — 各リーグ内で総当たり戦を実施
4. **決勝トーナメント** — 各リーグ上位2チームで準決勝・決勝・3位決定戦
5. **順位確定** — 勝敗・得失点差による自動計算 ＋ 手動調整

### 1試合の流れ

1. **対戦カード生成** — 管理者がリーグ内の対戦を自動生成し、日時・会場を設定
2. **オーダー提出** — 各チームが 5 種目（WD・XD・MD3・MD2・MD1）の選手を登録
3. **オーダー公開** — 管理者が双方のオーダーを確認・公開し、試合を開始
4. **試合進行** — 審判がスコアを種目ごとに入力
5. **結果確定** — 全種目終了後に運営が承認し、勝敗が集計される
