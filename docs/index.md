本マニュアルでは **東大リーグ団体戦** の運営支援システムの使い方を、役割ごとに説明します。

## 対象読者

| 役割       | セクション                                                                             |
| ---------- | -------------------------------------------------------------------------------------- |
| 大会運営者 | 管理者マニュアル（セットアップ・チーム登録・対戦生成・順位管理）                       |
| 出場者     | 出場チームマニュアル（オーダー提出）・審判マニュアル（スコア入力・取り消し・棄権処理） |
| 観戦者     | 観戦者向け（ライブスコア・順位の見方）                                                 |

## システム概要

本システムは、東大リーグの**団体戦**に特化した運営・スコア管理アプリです。

### 大会の流れ

1. **セットアップ** — イベント名・使用ルールの設定
2. **チーム登録** — 参加チームと選手を A/B の2リーグに振り分け
3. **予選（グループステージ）** — 各リーグ内で総当たり戦を実施
4. **決勝トーナメント** — 各リーグ上位2チームで準決勝・決勝・3位決定戦
5. **順位確定** — 勝敗・得失点差による自動計算＋手動調整

### 試合の流れ

1. **対戦カード生成** — 管理者がリーグ内の対戦を自動生成
2. **オーダー提出** — 各チームが5種目の選手を登録
3. **試合進行** — 審判が1種目ずつスコアを入力
4. **結果確定** — 試合終了時に自動ロック、勝敗が集計される
