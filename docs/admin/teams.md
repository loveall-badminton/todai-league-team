チームを作成し、選手を登録して A / B リーグに振り分ける手順をご案内します。

## チームの作成

1. サイドバーの「**チーム**」をクリックする
2. 右上の「**＋ 追加**」をクリックする
3. **チーム名**（正式名称）と**略称**を入力する
   - 略称は任意です。スペースが限られる場面で使用されます
4. 「作成」をクリックする

作成したチームは、**A リーグ / B リーグのいずれかに振り分ける**必要があります。チーム詳細画面の「リーグ」プルダウンから選択し、「保存」をクリックしてください。

> [!TIP]
> チームの並び順はドラッグ＆ドロップで変更できます。この並び順は対戦表やライブページの表示順に反映されます。

## 選手の登録

チーム詳細画面で、選手を1人ずつ登録します。

1. チーム名をクリックして詳細画面を開く
2. 「1人ずつ追加」タブで**氏名**と**性別**を入力する
3. 「追加」をクリックする

### 性別の設定について

選手の性別は**オーダー提出時の検証**に使用されます。正しく設定されていないとオーダーを提出できません。

| 種目               | 必要な性別構成   |
| ------------------ | ---------------- |
| WD（女子ダブルス） | 女性選手2名      |
| XD（混合ダブルス） | 男性1名・女性1名 |
| MD（男子ダブルス） | 男性選手2名      |

> [!CAUTION]
> 性別が「未設定」のまま登録すると、オーダー提出時に検証エラーが発生します。登録後に必ずご確認ください。

## 選手の一括登録

選手が多い場合は、一括登録機能をご利用ください。

1. チーム詳細画面で「**一括登録**」タブをクリックする
2. 1行に1名ずつ氏名を入力する（例：`山田 太郎`）
3. 「登録」をクリックする
4. 登録後、各選手の性別を1人ずつ編集する

> [!NOTE]
> 一括登録では性別を設定できません。登録後に個別に編集していただく必要があります。

## 選手の並び順

選手の表示順もドラッグ＆ドロップで変更できます。この順序は、試合開始時の**初期サーバー・レシーバー選択画面**での表示順に影響します。よく出場する選手を上位に並べておくと操作がスムーズです。
