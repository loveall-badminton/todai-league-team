管理画面へのログインから、大会の基本設定までの手順をご案内します。

## アカウント作成（初回のみ）

システムを初めてご利用になる際は、`/auth/bootstrap` にアクセスして管理者アカウントを作成してください。

1. ブラウザで `/auth/bootstrap` を開く
2. **ID**・**パスワード**・**表示名** を入力する
3. 「アカウントを作成」をクリックする

> [!NOTE]
> `/auth/bootstrap` は初回のみ有効です。管理者アカウントを作成した後は、このページにはアクセスできなくなります。追加アカウントは、ログイン済みの管理者アカウントで「設定 > ユーザー管理」から発行してください。

作成後は `/auth/login` からログインしてください。ログインに成功すると、ホーム画面（ライブ表示）に遷移します。

## 大会基本設定

ログイン後、サイドバーの「**設定**」から以下の項目を設定してください。

### 大会名

大会の名称を入力します。ライブページや各画面のヘッダーに表示されます。

### 得点ルール

初期状態では3種類のルールが登録されています。

| 使用場面         | ゲーム数           | 勝利点 | 上限点 |
| ---------------- | ------------------ | ------ | ------ |
| 予選             | 3ゲーム（2本先取） | 15点   | 21点   |
| 決勝トーナメント | 3ゲーム（2本先取） | 21点   | 30点   |
| 順位決定再試合   | 1ゲーム            | 21点   | 30点   |

各ルールの名前は自由に変更できます。「設定」画面の「得点ルール」セクションで、フェーズごとに使用するルールを選択してください。選択したルールは**対戦生成時**に自動適用されます。

> [!WARNING]
> 得点ルールの変更は**既存の対戦には反映されません**。ルールは対戦生成時の設定で固定されます。対戦を生成する前にご確認ください。

### オーダー公開ポリシー

オーダーをどのタイミングで公開するかを設定します。

- **試合開始時に公開**（推奨）— 試合が始まった時点で双方のオーダーが自動公開されます
- **手動公開** — 管理者が「公開」ボタンを押した時点で公開されます

## アカウント管理

「設定 > ユーザー管理」から、運営・チーム用のアカウントを発行・削除できます。

| 種別           | 権限                                                 |
| -------------- | ---------------------------------------------------- |
| 運営（管理者） | 全機能にアクセス可能                                 |
| チーム         | 割り当てたチームのオーダー提出・担当試合の審判が可能 |
| 一般参加者     | ログイン後の閲覧のみ（管理・オーダー操作は不可）     |

チームアカウントを作成する際は、**種別で「チーム」を選択し、対象チームを必ず紐づけて**ください。チームが紐づいていない場合、オーダー提出画面にアクセスできません。

> [!TIP]
> アカウントの ID・パスワードは各チームの担当者にお伝えください。ID・パスワードを変更したい場合は「編集」から行えます。
