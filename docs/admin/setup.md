管理画面へのログインから、大会の基本設定までの手順を説明します。

## アカウント作成

システムを初めて使うときは、`/auth/bootstrap` にアクセスして管理者アカウントを作成します。

1. ブラウザで `/auth/bootstrap` を開く
2. ユーザー名・パスワード・表示名を入力
3. 「アカウントを作成」をクリック

> [!NOTE]
> 初回のみ `/auth/bootstrap` が有効です。管理者アカウント作成後は、このページにはアクセスできなくなります。追加アカウントは、作成済みの管理者アカウントを用いて「アカウント管理」から作成してください。

以降は `/auth/login` からログインします。

## 大会基本設定

ログイン後、「設定」メニューから以下の項目を設定してください。

### イベント名

大会の名称を設定します。ライブページや各画面のヘッダーに表示されます。

### 得点ルール

初期状態では3種類のルールが登録されています。各ルールの名前は編集できます。

| 使用場面         | ゲーム数           | 勝利点 | 上限点 |
| ---------------- | ------------------ | ------ | ------ |
| 予選             | 3ゲーム（2本先取） | 15点   | 21点   |
| 決勝トーナメント | 3ゲーム（2本先取） | 21点   | 30点   |
| 順位決定再試合   | 1ゲーム            | 21点   | 30点   |

「設定」画面の「得点ルール」セクションで、フェーズごとに使用するルールを選択します。選択したルールは**対戦生成時**に自動適用されます。

> [!WARNING]
> 得点ルールの変更は**既存の対戦に影響しません**。ルールは対戦生成時にその時点のデフォルト値で固定されます。

### オーダー公開ポリシー

オーダーをどのタイミングで公開するかの設定です。

- **試合開始時に公開**: 試合が始まった時点で自動で公開
- **手動公開**: 管理者が「公開」ボタンを押した時点で公開

## アカウント管理

「設定 > アカウント」メニューから、以下のロールのアカウントを追加・削除できます。

| ロール | 権限                                       |
| ------ | ------------------------------------------ |
| 管理者 | 全機能にアクセス可能                       |
| チーム | 割り当てたチームのオーダー提出・審判が可能 |

チームアカウントを作成する際は、そのアカウントが所属する**チームを必ず紐づけて**ください。紐づけがないと、オーダー提出画面や審判画面にアクセスできません。
