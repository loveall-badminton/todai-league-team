予選リーグの順位決定ロジックと、決勝トーナメントの運用手順をご案内します。

## 予選順位表

「**予選**」メニューからリーグを選択すると、順位表と総当たり対戦の一覧を確認できます。順位表には以下の情報が表示されます。

| 列               | 内容                                  |
| ---------------- | ------------------------------------- |
| 順位             | 現在の計算上の順位                    |
| チーム名         | チームの正式名称                      |
| 各チームとの対戦 | 対戦相手ごとの種目スコア（勝数–負数） |
| 団体             | 勝った対戦の数（勝–負）               |
| 種目             | 獲得した種目の数（勝–負）             |
| ゲーム           | 獲得したゲームの数（勝–負）           |

## 順位計算ルール

順位は東大リーグの競技規則に基づき、以下の優先順位で決定されます。

| 優先度 | 条件                         | 説明                           |
| ------ | ---------------------------- | ------------------------------ |
| 1      | 手動順位                     | 管理者による直接の順位指定     |
| 2      | 対戦勝数                     | 勝った対戦の数                 |
| 3      | 直接対決                     | 当該チーム同士の対戦結果       |
| 4      | 種目勝数                     | 獲得した種目の数               |
| 5      | 同一順位チーム間の種目勝数   | 並んだチーム間での種目勝ち数   |
| 6      | ゲーム勝数                   | 獲得したゲームの数             |
| 7      | 同一順位チーム間のゲーム勝数 | 並んだチーム間でのゲーム勝ち数 |
| 8      | 順位決定再試合               | 21点1ゲームの追加試合          |

## 手動順位調整

自動計算では対応できないケースや、特別な事情がある場合に手動で順位を調整できます。

1. 順位表の「手動順位」列に数字を直接入力する
2. 必要に応じて「理由」を入力する
3. 「保存」をクリックする

> [!WARNING]
> 手動順位を設定すると、そのチームの自動計算は無効になります。解除するには、入力した値をクリアして保存してください。

## 決勝トーナメントの構造

```
準決勝1: A組1位 vs B組2位
準決勝2: A組2位 vs B組1位

決勝:      準決勝1の勝者 vs 準決勝2の勝者
3位決定戦: 準決勝1の敗者 vs 準決勝2の敗者
5位決定戦: A組3位 vs B組3位
```

> [!TIP]
> 決勝トーナメントのスコアリングルールは「決勝用」（21点3ゲーム）がデフォルトです。設定画面から変更できます。

## 最終確認

すべての対戦が終了したら、以下の項目をご確認ください。

1. 予選 — 全対戦が「確定」状態になっているか
2. 決勝 — 決勝・3位決定戦・5位決定戦の結果が正しいか
3. 順位表 — 最終順位が意図した通りか
