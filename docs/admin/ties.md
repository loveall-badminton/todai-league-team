対戦カードの生成から、試合の進行管理までの手順を説明します。

## 予選（グループステージ）

### 総当たり戦の生成

1. 「予選」メニューからリーグ（A または B）を選択
2. 「総当たり戦を生成」ボタンをクリック
3. 自動的にリーグ内の全チームの組み合わせが生成される

生成された対戦は「対戦管理」画面で一覧できます。

### 対戦のスケジュール

各対戦について、以下の情報を設定します。

- **開始予定時刻**
- **会場**（第一体育館 / 第二体育館）
- **コートブロック**（使用するコートの範囲）
- **オーダー提出期限**

> [!TIP]
> オーダー提出期限は、開始予定時刻の10分前に自動設定されます。手動で変更することも可能です。

## 決勝トーナメント

### 決勝戦の生成

1. 「決勝」メニューを開く
2. 「準決勝を生成」をクリック → A組1位 vs B組2位、A組2位 vs B組1位 が自動生成
3. 「決勝・3位決定戦を生成」をクリック → 準決勝の勝者同士・敗者同士で自動生成
4. 必要に応じて「5位決定戦を生成」

### 順位決定再試合

勝敗・得失点差で決着がつかない場合、21点1ゲームの**順位決定再試合**を実施します。

1. グループ画面で「順位決定再試合を作成」をクリック
2. 対象チームと理由を選択
3. 生成された対戦を通常の対戦と同様に進行

## 対戦の状態遷移

各対戦は以下の状態を遷移します。

1. **予定** — 生成直後。オーダー提出待ち
2. **提出済み** — 両チームのオーダーが提出済み
3. **開始可** — オーダー公開済み、試合開始可能
4. **進行中** — いずれかの種目が進行中
5. **結果確認待ち** — 全種目終了、管理者による結果確定待ち
6. **確定** — 結果確定済み

> [!NOTE]
> 全種目が終了すると自動的に「確定」状態になります。手動での確定操作は不要です。
