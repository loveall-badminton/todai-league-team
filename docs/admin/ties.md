対戦カードの生成から試合の進行管理までの手順をご案内します。

## 対戦の状態遷移

各対戦は以下の順序で状態が遷移します。

| 状態         | 説明                                         |
| ------------ | -------------------------------------------- |
| オーダー待ち | 生成直後。いずれかのチームのオーダーが未提出 |
| 提出済み     | 両チームのオーダーが提出済み                 |
| 開始可       | 両チームのオーダー承認済み、試合開始可能     |
| 進行中       | いずれかの種目が進行中                       |
| 結果確認待ち | 全種目終了、運営による結果承認待ち           |
| 確定         | 結果確定済み                                 |

## 対戦一覧

サイドバーの「**対戦管理**」から、すべての対戦を一覧できます。タブで「Aリーグ」「Bリーグ」「決勝トーナメント」のほか、「承認待ち」「開始可」「結果確認待ち」といった状態でも絞り込めます。

対応が必要な対戦（オーダー承認待ち・開始できる対戦・結果確認待ち）がある場合は、一覧の上部に「**要対応**」バナーが表示されます。件数をクリックすると該当する対戦に絞り込めます。

## 予選（グループステージ）

### 総当たり戦の生成

1. サイドバーの「**予選**」からリーグ（A または B）を選択する
2. 「**総当たり生成**」ボタンをクリックする
3. 自動的にリーグ内の全チームの組み合わせが生成される

> [!WARNING]
> すでに対戦が存在する状態で再生成すると、既存の対戦と重複することがあります。初回生成後は原則として再生成しないようご注意ください。

### 対戦のスケジュール設定

各対戦の「詳細」から以下の情報を設定できます。

- **開始予定時刻**
- **会場**（体育館・コートなど）
- **オーダー提出期限**

> [!TIP]
> オーダー提出期限は、開始予定時刻の 10 分前が自動設定されます。手動で変更することも可能です。

## 対戦詳細

対戦詳細画面では、進行状況・種目別結果・オーダー内容をひとめで確認できます。

画面上部のステッパーで現在の状態（オーダー提出 → オーダー確認 → 試合開始 → 試合進行 → 結果確定）が分かります。

### オーダーの承認と公開

両チームのオーダーが提出されると「提出済み」状態になります。チームごとに内容を確認し、「承認する」をクリックしてください。承認後のオーダーはチーム側で編集できなくなります。誤って承認した場合は「承認を解除」で差し戻せます。

**両チームの承認が完了すると「対戦を開始」ボタンが押せるようになります。** 開始時点で未公開のオーダーは自動的に公開されます。

開始前に相互公開したい場合は、両チーム提出後に表示される「オーダー公開」ボタンを使用してください（「公開を取り消す」で戻せます）。

### 打ち切り

一方のチームが3勝して対戦の勝敗が確定している場合、「残り種目を打ち切る」ボタンで未終了の種目をまとめて中止し、対戦を終了状態にできます。**この操作は取り消せません。** 打ち切らずに残りの種目を消化することもできます（全種目終了時点で「結果確認待ち」になります）。

### 対戦の削除

対戦詳細画面の「対戦を削除」から、対戦を種目・オーダーごと削除できます。進行中などで通常削除できない場合は、確認ダイアログの「強制削除する」にチェックを入れて削除します。

### 結果確認

全種目が終了すると「結果確認待ち」状態になります。

結果確認は2段階で行います。

1. **種目ごとの承認** — 対戦詳細画面の種目一覧で、各種目の「運営承認」をクリックして結果を確認する
2. **対戦の確定** — 全種目の承認が完了すると対戦レベルの確定ボタンが表示されるので、クリックして「確定」状態に移行する

> [!NOTE]
> 承認済みの種目は「承認解除」で取り消せます。対戦が「確定」に移行する前であれば、審判画面での再操作も可能です。

## 決勝トーナメント

### 決勝トーナメントの生成

1. サイドバーの「**決勝**」を開く
2. 「**準決勝・5位決定戦生成**」をクリック → A組1位 vs B組2位、A組2位 vs B組1位 が自動生成される
3. 準決勝が確定したら「**決勝・3位決定戦生成**」をクリック → 準決勝の勝者同士・敗者同士で自動生成される

> [!NOTE]
> 決勝トーナメントの生成には、Aリーグ・Bリーグの全対戦が完了している必要があります。

### 順位決定再試合

勝敗・得失点差で決着がつかない場合、21点1ゲームの**順位決定再試合**を実施します。

1. グループ画面で「順位決定再試合を作成」をクリックする
2. 対象チームと理由を選択する
3. 生成された対戦を通常の対戦と同様に進行する
