ライブページで試合のスコアや順位をリアルタイムで確認する方法をご案内します。ログインは不要です。

## ライブページへのアクセス

ブラウザで `/live` を開いてください。「**進行表**」と「**順位表**」の2つのタブが用意されています。

## 進行表

進行表では、Aリーグ・Bリーグの全対戦を一覧で確認できます。

| 表示                              | 意味                                 |
| --------------------------------- | ------------------------------------ |
| 緑の点（点滅）＋ 進行中           | 現在試合が行われています             |
| 橙の点 ＋ オーダー待ち等          | 試合開始前（提出待ち・開始待ちなど） |
| グレーの点 ＋ 結果確認待ち / 確定 | 試合が終了しています                 |
| スコア（例：2–1）                 | 種目の勝敗数（左が先に記載のチーム） |

対戦をタップすると、種目ごとの詳細スコアを確認できます。

## 順位表

順位表では、Aリーグ・Bリーグの現在の順位をひとめで確認できます。

| 列               | 内容                                         |
| ---------------- | -------------------------------------------- |
| 順位             | 現在の計算上の順位（試合が進むと変動します） |
| チーム名         | チームの正式名称                             |
| 各チームとの対戦 | 対戦相手ごとの種目スコア（勝数–負数）        |
| 団体             | 勝った対戦の数（勝–負）                      |
| 種目             | 獲得した種目の数（勝–負）                    |
| ゲーム           | 獲得したゲームの数（勝–負）                  |

> [!TIP]
> 順位はリアルタイムで自動更新されます。ページをリロードしなくても最新の情報が反映されます。

## リアルタイム接続について

画面にリアルタイム接続の状態が表示されます。「**接続中**」の場合は WebSocket によるリアルタイム更新が有効です。接続が切れると自動で再接続を試みます。

接続状態に関わらず、一定間隔でのポーリングによる自動更新も行われます。
